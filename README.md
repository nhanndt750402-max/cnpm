# LivingDocs Test Repository

This repository is used to test documentation search.

## Calculator

The Calculator class supports basic operations.

Available operations:
- add: Add two numbers.
- subtract: Subtract two numbers.
- multiply: Multiply two numbers.

## User Service

The UserService class manages user information.

Available methods:
- get_user: Find a user by ID.
- create_user: Create a new user.
